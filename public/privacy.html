개인정보처리방침

라이더 화장실맵 · 시행일 2026년 12월 1일

라이더 화장실맵(이하 "서비스")은 웹사이트와 안드로이드 앱으로 전국의 화장실 위치와 정보를 제공하고, 누구나 화장실 정보를 등록·수정할 수 있는 서비스입니다. 지도 보기는 로그인 없이 쓸 수 있고, 화장실 등록·수정·투표와 순위표 참여는 구글 계정으로 로그인해야 합니다. 필요한 최소한의 정보만 처리하며, 구글 계정의 이메일·이름·사진은 저장하지 않습니다.

1. 처리하는 정보와 목적

항목목적보관 기간
위치 정보(현재 위치 좌표) 지도에 내 위치 표시, 가까운 화장실 찾기, 걷는 길 경로 표시 서비스 서버에 저장하지 않음 (가까운 화장실 검색 때 한 번 쓰고 버림)
구글 계정 고유번호(구글이 앱별로 주는 숫자 ID) 로그인 상태 유지, 내가 올린 정보·점수 연결 탈퇴(삭제 요청) 전까지
닉네임, 주 활동 지역(시·군·구), 주로 타는 플랫폼(배민·쿠팡 등), 점수 순위표 표시(닉네임·지역·플랫폼·점수는 다른 이용자에게 공개), 내가 올린 화장실에 닉네임 표시 탈퇴(삭제 요청) 전까지
기기 구분 값(앱이 처음 실행될 때 만드는 무작위 ID)과 IP 주소의 암호화된 요약값(해시) 등록·수정·신고 남용 방지(횟수 제한, 중복 신고 방지), 문제 글 추적 화장실 정보·수정 기록이 남아 있는 동안 (원래 IP 주소와 ID는 저장하지 않음)
이용자가 직접 올린 내용: 화장실 이름, 주소, 비밀번호, 이용 시간, 설명, 별점, 맞아요/틀려요 투표, 신고 사유 지도에 공개해 다른 이용자와 공유, 신고 처리 삭제 요청이나 운영자 삭제 전까지
접속 기록(IP 주소, 접속 시각) 서버 오류 확인, 공격 차단 서버 메모리·로그에 일시 보관 후 삭제

위치 정보는 사용자가 휴대폰·브라우저에서 위치 권한을 허용한 경우에만 사용되며, 언제든지 설정에서 권한을 끌 수 있습니다. 위치 권한을 허용하지 않아도 지도와 화장실 정보는 볼 수 있습니다.

등록한 내용은 누구나 볼 수 있습니다. 설명 칸 등에 전화번호 같은 개인정보를 적지 마세요.

2. 개인정보의 제3자 제공 및 외부 서비스

서비스는 개인정보를 판매하거나 제3자에게 제공하지 않습니다. 다만 기능 제공을 위해 아래 외부 서비스를 이용합니다.

  • Google 로그인: 구글 계정으로 로그인할 때 Google 이 본인 확인 결과(계정 고유번호가 담긴 토큰)를 서비스에 전달합니다.
  • 네이버 지도(NAVER Cloud Platform): 지도 표시와 주소 검색. 지도를 불러올 때 네이버에 접속 정보가 전달될 수 있습니다.
  • FOSSGIS 경로 서비스(routing.openstreetmap.de): "내 근처"를 누를 때 걷는 길 경로를 계산하기 위해 출발지(현재 위치)와 도착지(화장실) 좌표를 보냅니다.
  • Render, Neon: 서버와 데이터베이스 운영(화장실 정보 저장).
  • Google AdMob(안드로이드 앱의 하단 광고): 광고를 보여주고 광고 성과를 측정하기 위해 Google이 광고 ID 등 기기 식별자, IP 기반 대략적 위치, 앱 사용·오류 정보를 수집할 수 있습니다. 맞춤 광고는 휴대폰 설정 → Google → 광고에서 끄거나 광고 ID를 삭제할 수 있습니다. 자세한 내용: Google 파트너 사이트·앱의 정보 사용 방식

화장실 기본 정보 일부는 공공데이터포털의 "전국공중화장실표준데이터"(공공누리)를 이용합니다.

3. 쿠키 · 기기 저장소

앱·브라우저 안에 기기 구분 값을 저장하고, 로그인 상태 유지(최대 180일)와 운영자 로그인에 쿠키를 사용합니다. 웹사이트에는 광고·추적용 쿠키를 사용하지 않습니다. 안드로이드 앱의 광고는 위 2항의 Google AdMob을 통해 제공됩니다.

4. 이용자의 권리 · 데이터 삭제 요청 방법

계정 삭제(탈퇴): 전화·문자 010-9410-9103 로 "계정 삭제 요청"과 닉네임을 알려 주세요. 본인 확인 후 3일 이내에 구글 계정 고유번호, 닉네임, 활동 지역, 플랫폼, 점수, 투표 기록을 삭제합니다. (등록한 화장실 정보는 다른 이용자를 위해 작성자 표시 없이 남을 수 있으며, 원하면 함께 삭제합니다.)

내가 등록한 화장실 정보나, 내 건물의 화장실 비밀번호 등을 지우고 싶다면:

  1. 앱에서 해당 화장실을 눌러 신고 → "건물 관계자예요"를 고르거나,
  2. 전화·문자 010-9410-9103 로 화장실 위치(주소)와 요청 내용을 알려 주세요.
  3. 확인 후 3일 이내에 해당 정보를 삭제하거나 비밀번호를 지우고 결과를 알려드립니다.

앱을 지우거나 앱 데이터를 삭제하면 기기에 저장된 기기 구분 값도 함께 지워집니다. 위치 정보는 서버에 저장하지 않으므로 삭제할 데이터가 없습니다.

5. 안전성 확보 조치

IP 주소와 기기 구분 값은 원래 값을 저장하지 않고 되돌릴 수 없는 해시로만 저장합니다. 신고·수정 기록은 운영자 비밀번호로 보호된 화면에서만 볼 수 있으며, 모든 통신은 HTTPS로 암호화됩니다.
